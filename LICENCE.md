## 🧩 About

**Halo Campaign Evolved helpers** is a curated list of Halo Campaign Evolved open-source tools:

- **Overlays** — on-screen helpers, layout notes, HUD reference viewer, checkpoint switcher
- **Quality-of-Life Helpers** — mission catalog, loadout notes, overlay notes
- **Research Notes** — encounter layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### 🎮 Campaign Helpers
- Checkpoint Switcher — resume study from any mission segment
- HUD Reference Viewer — visualize objective and ammo panels
- Run Notes — record and review campaign encounters
- Playback Speed — adjust mission playback for study (0.1x to 5x)

### 🎨 Catalog & Loadout
- Loadout Catalog — browse weapons, vehicles, and armor notes
- Custom Loadout Notes — organize player presets
- Objective Trail — improved mission marker visibility

### 🏋️ Practice Layout
- Mission Mode Notes — segment study on any campaign layout
- Difficulty Notes — manually review difficulty modifiers in the editor
- Movement Buffer Notes — chain complex maneuvers in practice
